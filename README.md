## 📂 Projetos

### 🍽️ DataPlate
Plataforma web responsiva para restaurantes, desenvolvida em grupo de 5 pessoas com **Scrum**.

- Cardápio digital via QR Code
- Pedidos em tempo real para a cozinha (WebSocket)
- Controle de mesas e reservas
- Painel administrativo com dashboards e classificação de pratos pela Matriz BCG
- **Stack:** Python, FastAPI, SQLAlchemy, PostgreSQL, Docker, JavaScript


### 🧾 Sistema de Fichas Técnicas
Sistema web que calcula o custo de receitas, a margem de lucro e o preço sugerido de produtos (por unidade e por kg).

- Fichas técnicas versionadas, com histórico de alterações
- Relatórios com alerta de produtos abaixo da margem mínima
- Integração com o banco Firebird de um ERP para importar produtos e preços
- Migração de SQLite para PostgreSQL (Supabase) e deploy no Render
- **Stack:** Python, FastAPI, PostgreSQL, JavaScript
